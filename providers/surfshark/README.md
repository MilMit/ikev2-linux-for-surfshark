# Surfshark provider data

This directory contains the provider schema used by the client.

`locations.example.json` intentionally contains **placeholder endpoints**.
Do not treat example data as a working Surfshark server list.

Before shipping real data, verify:

- redistribution rights for server metadata;
- certificate redistribution terms;
- current Surfshark IKEv2 hostname/IP values;
- update/signature mechanism for the bundled database.

Secrets must never be committed here.
